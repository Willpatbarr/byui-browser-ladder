byui-browser ladder tests

Open each level in the browser. A level passes when it shows a large SUCCESS. L2 and up show FAIL by default.

  1. L0: plain text
  2. L1: static HTML
  3. L2: inline and style-tag CSS
  4. L3: external stylesheet, image, web font
  5. L4: links, forms, back/forward
  6. L5: JavaScript DOM changes
  7. L6: fetch and timers
  8. L7: real-world sites
