The Ladder

Eight test pages, one per complexity level. Open a level in the browser: a big SUCCESS means it passes. The browser is complete when every level passes.

  1. L0 Plain text No tags at all. If it renders, it passes.
  2. L1 Static HTML Headings, paragraphs, lists and links with default styling.
  3. L2 CSS Inline styles and a style block reveal SUCCESS.
  4. L3 External resources Linked stylesheet, image and web font.
  5. L4 Interaction Links, form submit, back and forward.
  6. L5 JavaScript A script changes the page.
  7. L6 Network and timers fetch and setTimeout.
  8. L7 Real-world sites Actual websites, checked by hand.

How a level passes

From L2 up, every page shows FAIL by default. Only the feature under test can swap it for SUCCESS, so a browser missing that feature never passes by accident.
